Designer Notes

Open questions + decisions

🔑 Auth Flow

SSO first or email+password? Ask PM. If SSO — which provider? Google + GitHub minimum.

⚡ Performance

Table with 10k+ rows — needs virtualisation. Tanstack Virtual? Check bundle size impact before committing.

📱 Mobile scope

Variant A collapses well. B is questionable at 375px. C (split panel) — probably desktop-only for v1.

🎨 Design system

Confirm accent color with brand before building. Blue placeholder only — client may want their own.

♿ A11y

Tab panels need keyboard nav. Focus ring must be visible at 3:1 ratio min. Run axe-core before QA sign-off.

🗓 Timeline

Wireframe review — this Friday. Prototype — 2 weeks. Dev handoff — end of month. Aim for Oct 31.
