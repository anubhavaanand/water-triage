Methodology
Each validation point links our composite risk score output to a government-issued baseline. Directional alignment (same high-risk districts) is accepted as confirmation — we are not claiming exact sample counts match habitation counts (different measurement units).

API State Sketches

Loading · Empty · Error

Required states for all API-backed views. DB must be running (`docker start watertriage-db`) or fallback loads data.json — now clean with `generated_at` field and correct counts.

Loading State

Shown while `/api/dashboard-data` fetches. Skeleton rows, no spinners.

→ Stop skeleton at 60s — escalate to error state if API doesn't respond

Empty State

When filter returns zero districts. Not an error — the filter is just too narrow.
