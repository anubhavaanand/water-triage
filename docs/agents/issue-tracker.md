# Issue Tracker

Issues for this project are tracked in **GitHub Issues** at:
https://github.com/anubhavaanand/water-triage/issues

We use the `gh` CLI for all issue operations:
- Create: `gh issue create`
- List: `gh issue list`
- View: `gh issue view <number>`
- Edit: `gh issue edit <number>`
- Close: `gh issue close <number>`

PRs as a request surface: **off** (external PRs are not added to the triage queue)
