# Triage Labels

The five canonical triage roles are used with their default label strings:

| Role | Label |
|------|-------|
| Needs Triage | `needs-triage` |
| Needs Info | `needs-info` |
| Ready for Agent | `ready-for-agent` |
| Ready for Human | `ready-for-human` |
| Won't Fix | `wontfix` |

These labels are created automatically when first used. No manual label management is required.
